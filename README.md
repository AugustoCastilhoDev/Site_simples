# Simple Website | Site Simples

## 📌 Description (EN)
This repository contains a **simple website** built using HTML, CSS, and JavaScript.  
The project demonstrates basic web development skills, including layout structure, styling, and simple interactivity such as theme change (dark/light mode) and button behavior.

It is a good example of core front-end fundamentals learned during the early stages of web development.

## 📌 Descrição (PT-BR)
Este repositório contém um **site simples** creado com HTML, CSS e JavaScript.  
O projeto demonstra habilidades básicas de desenvolvimento web, incluindo estrutura de layout, estilização e interatividade simples como mudança de tema (modo escuro/claro) e comportamento de botões.

É um bom exemplo dos fundamentos de front-end aprendidos nas fases iniciais.

## 🚀 Technologies / Tecnologias
- HTML5  
- CSS3  
- JavaScript  

## 🎯 What I Learned (EN)
- Structuring a web page with HTML  
- Applying styles using CSS  
- Adding simple interactivity with JavaScript  
- Handling DOM events and theme toggling  

## 🎯 O que eu aprendi (PT-BR)
- Estrutura de página utilizando HTML  
- Aplicação de estilos com CSS  
- Adição de interatividade simples com JavaScript  
- Manipulação do DOM e alternância de tema  

## ▶️ How to Run / Como executar
1. Clone this repository (clone este repositório)  
2. Open the `index.html` file in a web browser (abra o arquivo `index.html` no navegador)
